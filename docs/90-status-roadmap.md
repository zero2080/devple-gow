# 90. 현황 / 로드맵

갱신: 2026-10-19 (이동 기술 38 후). 대상: 「갓 오브 워」(1편) 한글판 SCKA_300.02 → macOS 네이티브 재구현 (Java 21 + LWJGL, OpenGL 4.1).

## 1. 실행
```bash
./gradlew :engine:run                                 # 원작 메인 메뉴 → 새 게임(ATHN01A) / 불러오기
./gradlew :engine:run --args="--game ATHN01A"         # 레벨 바로 시작 (다른 레벨 이름도 가능)
./gradlew :engine:run --args="--hero --enemy R_MIN"   # 평지 전투 연습
./gradlew :engine:test                                # 원본 데이터 기반 테스트 (gow-rom 필요)
```

## 3. 원본 데이터 vs 근사 원칙
- 수치·분기·텍스트·UI 로직은 **원본 데이터에서 그대로** 읽는다 (TWK, CombatFile, FLP 스크립트, ESC 스크립트).
- 근사는 문서에 "[추정]"/"근사" 로 표시: 공격 히트박스(데이터 없는 부위만 정면 구), 적 AI 판단, 점프 초속, 단위(1m≈16), 카메라 일부.
