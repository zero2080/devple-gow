# 46. 렌즈플레어 — SCR_LensFlare (`fx/LensFlare`, `fx/LensFlares`)

원작의 "렌즈플레어" 는 여러 장의 고스트가 화면 중심을 지나 늘어서는 효과가 **아니다**. 광원 하나에 **화면 정렬 스프라이트 하나**
(머티리얼 텍스처) 를 가산으로 그리고, 그 밝기를 GS 에서 계산한 **가림 비율** 로 조절한다 [확실: 렌더 0x20E990 에 스프라이트 반복문 없음].

## 1. 데이터
등록 0x21D328 (`SCR_LensFlare` 문자열 0x2B9640), 생성 0x2469B0 → 0x20E728 (객체 0x30 바이트). 데이터 4개 인스턴스 (템플릿 4개 별도):

| 레벨 | 소유 GO | 크기 | 가림 상자 | 머티리얼 | 위치 (관절 0) |
|---|---|---|---|---|---|
| OLYMP01 | gosunflare | 256 | 8 | starFlare → MAT_starFlare (ANM_starFlare) | (−1600, 2400, −4736) |
| PAND04F | golensflare | 508.28 | 64 | FLARE → MAT_flare | (−1184, 2784, −2272) |
| PAND04G | golensflare | 575 | 64 | FLARE → MAT_flare | (−256, 4320, −6912) |
| PAND04G | golensflare1 | 700 | 64 | FLARE → MAT_flare | (−256, 3456, −1472) |

값 (인스턴스 32 바이트) [확실: 0x20E728]:

| 오프셋 | 형 | 객체 | 의미 |
|---|---|---|---|
| 0x00 | f32 | +0x24 | 스프라이트 크기 (원작 화면 화소, 전체 폭) |
| 0x04 | f32 | +0x28 | 가림 판정 상자 크기 (화소) |
| 0x08 | char[24] | +0x20 | 머티리얼 이름 — `"MAT_%s"` (0x2B93B8) 로 만들어 0x17A7B8 로 조회, 머티리얼 +0x60 → +0x38 = 텍스처. 조회는 대문자 해시라 대소문자 무시 ("FLARE" → MAT_flare) |

- 객체: +0x18 = 값, +0x1C = 스크립트 엔티티, +0x2C = 렌더 목록 등록 여부. 렌더 목록 0x15F288(목록 0x3300D0, 층 2, 우선순위 5),
  엔티티 +0x34/+0x38 = 켬 0x20E898 / 끔 0x20E8F8 (등록·해제) [확실].
- 위치 0x20E948: 소유 GO 에 스켈레톤이 있으면 엔티티 +0x46 관절의 월드 (0x136BD8), 없으면 GO +0x50 [확실]. 데이터는 모두 관절 1개 → 관절 0.

## 2. 렌더 0x20E990
1. 보기 공간 투영 0x169C80 → 깊이가 렌더 문맥 +0x384..+0x388 (근/원) 밖이면 생략. 화면 좌표·GS Z = 0x169D18 [확실].
2. 반폭: 스프라이트 = int(크기·½) 화소, 가림 상자 = int(상자·½) 화소. 상자를 화면 [0, W−1]×[0, H−1] 로 자르고, 스프라이트 사각형이
   화면 밖이면 생략 (0x20EA88..0x20EB88) [확실].
3. **첫 패스** (0x20EB8C..0x20ED80, 문맥 1): 머티리얼 텍스처 (0x167650), RGBAQ 0x40404040 (변조 ½), ALPHA_1 = 0x68 + FIX 0x80
   (Cs·1 + Cd, 고정 가산), TEST_1 = 0x51001 (ATST NEVER + AFAIL FB_ONLY = Z 안 씀, ZTST GEQUAL = 빛의 Z 로 깊이 시험), FRAME_1 = 화면.
   → **화소 단위로 가려지는 반 밝기 플레어** [확실: 레지스터 값, 추정: 화면에 남는 결과].
4. **가림 판정** (0x20ED84..0x20F5A8): 상자 (±1 화소) 의 알파를 0 으로 지우고 (ALPHA 0x6A = Cd 유지, RGBAQ 0), 빛의 Z 로 깊이 시험한
   흰 사각형을 알파 `0xC0 · min(자른 Δx, Δy) / (반폭·2)` 로 그린다 (0x20ED5C/0x20ED8C). 그 영역을 작업 버퍼 (0x330A24) 로 옮기며
   쌍선형 (TEX1_2 = 0x60) 으로 64 → 32 → 16 → 8 → 4 → 2 → 1 화소 축소 (스프라이트 0x400/0x200/…/0x10, 12.4 고정소수) → 평균 알파.
   그 1 화소를 텍스처 크기로 늘려 작업 버퍼 알파에, 플레어 텍스처 RGB 를 FBMSK 0xFF000000 (알파 보존) 으로 같은 버퍼에 복사 [확실: GS 패킷,
   추정: 각 축소 단계의 표본 위치].
5. **마지막 패스**: 작업 버퍼를 텍스처 (TCC 1) 로 화면에 ALPHA_1 = 0x48 (Cs·As + Cd), RGBAQ 0x80808080 → 플레어 × As,
   As = **1.5 · 보이는 비율 · 자름 비율** (8비트 상한) [확실: 0xC0 상수, 추정: 축소 평균 = 비율].

정리: 보이는 광원 = 반 밝기 (화소 단위 가림) + 1.5배 × 보이는 비율 (상자 평균) 의 두 겹. 상자가 화면 가장자리에서 잘리면 흐려지고,
광원이 일부 가려지면 전체 플레어가 비율만큼 흐려진다.

## 3. 엔진 (`fx/LensFlare` 계산, `fx/LensFlares` GL, `LevelScene` 연결)
- `LensFlare.defs(EnvParams)` = 인스턴스 값 파싱, `clip` / `onScreen` / `clipRatio` / `visibleFraction` / `intensity` = 위 2–5 의 식.
- `LensFlares` 는 레벨 진입 때 소유 GO 배치의 관절 0 위치와 머티리얼 텍스처를 찾고, `LevelScene.renderEffects` (게임: 캐릭터·이펙트 뒤) /
  `render` (뷰어) 끝에서 그린다:
  1. 투영 → NDC 깊이 [−1, 1] 밖이면 생략. 화면 화소 = 창 높이 / 448 배 [추정: 원작 프레임 640×448].
  2. 가림 상자의 깊이 버퍼를 `glReadPixels(GL_DEPTH_COMPONENT)` 로 읽어 `빛 깊이 ≤ 장면 깊이` 비율 [근사: GS 알파 누적·쌍선형 축소 대신 화소 평균].
  3. 첫 패스: 빛의 NDC 깊이로 그린 사각형, GL_LEQUAL 깊이 시험·깊이 쓰기 없음, (ONE, ONE), 텍스처 × ½.
  4. 마지막 패스: 깊이 시험 없이 (ONE, ONE), 텍스처 × `intensity`.
- MAT_starFlare 의 ANM_starFlare 층 0 슬롯 5 (0 → 2π, 1.67초 반복) 를 스프라이트 UV 회전으로 [추정: 슬롯 5 = 회전 라디안]. 회전으로 텍스처
  밖이 된 UV 는 그리지 않는다 [근사].
- 거울 반사 패스에서는 그리지 않는다. 끄기: `GOW_LENSFLARE=off` 또는 `-Dgow.nolensflare`.
- 테스트 `LensFlareTest` (3): 4개 레벨 값, 자름·자름 비율·화면 판정, 보이는 비율·세기 (1.5 배).
