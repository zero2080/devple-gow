# 44. 구현: 노멀맵 (원작에 없는 선택 기능)

```bash
GOW_NORMALMAP=on ./gradlew :engine:run --args="--game ATHN04C"     # 켜고 시작
# 실행 중 5 키 = 켜기/끄기 (콘솔에 "노멀맵 (원작에 없음) 켬/끔")
```

## 1. 왜 원작에 없는 기능인가
- 원작 PS2 판은 노멀맵이 없다. GS 는 픽셀 셰이더가 없고, VU1 마이크로코드는 정점 단위 조명만 한다 (16 문서 §3: 렌더 플래그 bit2 조명 / bit1 조명+환경).
- 레벨 메시는 법선 자체가 없다 — 조명이 정점색에 구워져 있다 (VU 프로그램 `0x…25`, 16 문서 §3, 04 문서). 캐릭터만 법선 + 실시간 조명.
- 그래서 이 기능은 **재구현의 선택적 시각 개선**이며 **기본 꺼짐**이다. 끄면 셰이더가 노멀맵 경로를 전혀 타지 않아 원작 재현 화면과 같다 (§6).

## 2. 노멀맵 출처 (텍스처마다, 우선순위)
1. **덮어쓰기 파일** `work/normalmaps/<텍스처 키>.png` (경로는 `-Dgow.normalmaps=폴더` 로 바꿀 수 있음).
   텍스처 키 = `WadAssets` 텍스처 캐시 키:
   - 보통 텍스처: TXR 이름 그대로 (예 `TXR_Athn04C012.png`)
   - 태그 지정 사본 (`textureBefore`, PTC 머티리얼): `이름@태그번호`
   - 애니메이션 텍스처 프레임: `이름#프레임번호`
   파일 규약: R/G/B = 법선 xyz·0.5+0.5, +X = +u (오른쪽), **+Y = +v (이미지 아래쪽, "DirectX/Y−" 규약)**, Z = 바깥.
   크기는 원본과 달라도 된다 (UV 정규화). 2 의 거듭제곱이 아니면 원본처럼 오른쪽·아래를 채운다.
2. **CPU 생성** (`NormalMapGen`, §3).

- 생성은 **게으르게**: 기능이 켜진 상태에서 그 텍스처를 처음 그릴 때 한 번 (`Texture.normalMap()`), 결과 GL 텍스처는 원본 텍스처에 붙어 함께 해제된다.
  꺼져 있으면 아무것도 만들지 않는다 (원본 ARGB 는 다시 디코드하는 공급자만 들고 있다; 애니 프레임만 잘린 배열을 보관).
- 측정 (스크린샷 240 프레임 동안 누적): ATHN04C 25 장 64 ms, OLYMP02 35 장 59 ms, PAND03A 113 장 86 ms, ATHN01A 82 장 54 ms,
  HDES01A 27 장 42 ms, ATHN04B 80 장 66 ms. 스크린샷 때 콘솔에 `노멀맵: 생성 n, 덮어쓰기 m, 누적 t ms` 를 찍는다.

## 3. 생성기 (`render/NormalMapGen`)
- 높이 h = 휘도 (0.299 R + 0.587 G + 0.114 B)/255. 팔레트 텍스처도 이미 디코드된 ARGB 로 받으므로 같다.
- 3×3 Sobel, 1/8 정규화 → 텍셀당 높이 차 gx, gy. n = normalize(−S·gx, −S·gy, 1), S = `NormalMaps.STRENGTH` = 4.
- 가장자리 주소: 텍스처의 반복 여부 그대로 — 반복이면 감싸기, 아니면 가장자리 복제 (clamp). 엔진의 WAD 텍스처는 모두 반복이다.
- 알파: α < 64 (`ALPHA_CUT`) 텍셀은 잘린 것 → 자기 법선은 평평 (0,0,1), 이웃 계산에서는 **중심 텍셀 높이로 대체** — 잘린 부분의 (보통 흰/검은) 색이 가짜 경사를 만들지 않는다.
  CUTOUT 알파 테스트 (0.75) 보다 낮게 잡아 반투명 가장자리 텍셀은 살린다.
- 2 의 거듭제곱 패딩 영역은 투명 → 평평.
- 테스트 `NormalMapGenTest`: 평평한 입력 → (0,0,1), 가로·세로 경사 → 예상 기울기 (clamp 가장자리 절반, 감싸기 이음), 알파 잘림 경계 → 평평, 부드러운 법선의 감김·이음 무관.

## 4. 셰이딩 (`basic.vert` / `skinned.vert` / `basic.frag`)
공통:
- 정점 셰이더가 월드 위치 `vWorldPos` 와 눈 위치 `vEye` = `inverse(uViewProj)·(0,0,1,0)` 의 동차 나눗셈을 넘긴다 (켤 때만 계산).
  눈을 VP 에서 구하므로 **거울 패스** (uViewProj = VP·R, 43 §9) 에서는 자동으로 반사된 눈이 된다 — 자바 쪽 추가 유니폼 없음.
- 탄젠트는 저장하지 않는다: 화면 미분 **코탄젠트 좌표계** (dFdx/dFdy 의 월드 위치·UV) 로 T, B 를 N 에 맞춰 만든다. UV 거울·회전·스크롤 (`uUvOffset`) 이 그대로 반영된다.
  미분은 `discard` 전에, 균일 분기 (`uNmOn`) 안에서 계산한다.
- 적용 대상: 머티리얼 **첫 레이어**, 블렌드 OPAQUE / CUTOUT / ALPHA, 텍스처가 있는 파트만. 추가 레이어 (환경맵·가산 등)·파티클·안개·FLP UI 는 손대지 않는다.
  노멀맵 텍스처는 유닛 2 (0 = 색, 1 = 안개 텍스처).

**조명 구운 레벨 메시** (uLit = 0):
- 기준 법선: 로드 때 `SmoothNormals` 로 위치가 같은 정점끼리 (UV 이음 무관) 면적 가중 면 법선을 모은다. 스트립마다 감김이 섞여 있어 (04 문서) 그룹 합과 반대면 뒤집어 더한다.
  이 값은 법선 없는 서브메시의 빈 법선 칸에 넣는다 — 그런 파트는 uLit = 0·환경 UV 꺼짐이라 원래 화면에서는 읽히지 않는다.
- 원작은 레벨 메시 뒷면 제거를 안 하므로 (43 §8) 보이는 쪽을 정해야 한다: 화면 미분 면 법선 nf = cross(dFdx p, dFdy p) 를 눈 쪽 (V = vEye − p) 으로 뒤집고,
  부드러운 법선을 nf 쪽으로 맞춘다. 둘의 내적이 0.5 이하 (모서리) 면 nf 를 쓴다. `gl_FrontFacing` 은 감김이 섞여 있어 쓰지 않는다 — 거울 패스의 `glFrontFace(GL_CW)` 와도 무관.
- 광원 L: 레벨 LGT 동적 조명은 렌더 플래그 0x800 모델 전용이라 (47 문서) 레벨 메시용 광원 데이터가 없다 → **카메라 위쪽에서 비추는 고정 방향** L = normalize(V + (0, 0.8, 0)).
- 밝기 배율 (구운 정점색은 그대로 두고 곱함):

  `factor = clamp(1 + k·(dot(N_map, L) − dot(N_geom, L)), lo, hi)`, k = 1.0, lo = 0.6, hi = 1.4 (`NormalMaps.DETAIL_*`).

  평평한 노멀맵이면 정확히 1, 요철은 ± 로 갈려 평균 밝기는 거의 그대로 → 원작 분위기 (구운 조명·안개) 유지. 안개는 그 뒤에 기존대로.

**법선 있는 메시** (캐릭터 `skinned.vert`, 조명 파트, uLit = 1): 기존 법선 (없으면 면 법선) 을 같은 코탄젠트 좌표계로 흔들어 기존 조명식 `0.35 + 0.65·max(n·L₀, 0)` 에 넣는다.

## 5. 토글
- 환경 변수 `GOW_NORMALMAP=on` → 시작부터 켬. 기본 꺼짐.
- 실행 중 **5 키** (`Engine` 루프에서 렌더 프레임마다 검사; 1/2/3 = 레벨 디버그, 4 = 환경 효과). 레벨·게임·뷰어 모든 씬에서 동작.
- 끄면 `uNmOn` 유니폼을 아예 설정하지 않는다 (기본 0) → 노멀맵 텍스처 바인딩·추가 GL 호출 없음.

- 엔진 스크린샷은 실행마다 조금씩 다르다 (파티클·실시간 시간). 같은 빌드 두 번의 차이를 잡음 바닥으로 두고 부모 커밋 빌드와 비교했다:

| 비교 (`--no-fx --ticks 240`) | 다른 화소 | 최대 채널 차 |

| ATHN04C 부모 vs 부모 | 111 (0.012%) | 1 |
| ATHN04C 부모 vs 이 빌드 (꺼짐) | 228 (0.025%) | 1 |
| OLYMP02 부모 vs 부모 | 6,941 (0.75%) | 3 |
| OLYMP02 부모 vs 이 빌드 (꺼짐) | 4,702 (0.51%) | 3 |
| PAND03A 부모 vs 부모 | 6,006 (0.65%) | 112 |
| PAND03A 부모 vs 이 빌드 (꺼짐) | 10,764 (1.17%) | 171 |

  레벨 뷰어 (`--level … --cam 0 --no-fx`) 도 ATHN04C 62 화소 (부모끼리 61), OLYMP02 7.6% 최대 6 (부모끼리 6.4% 최대 4), PAND03A 0.9% 최대 1. 모두 잡음 범위 (PAND03A 큰 차이는 불·용암 파티클 위치).
  셰이더 쪽은 꺼짐일 때 `nmFactor = 1.0` 곱과 같은 법선 식만 남아 산술상 같다.

## 7. 한계
- 높이를 휘도에서 추정하므로 "색 = 높이" 가 아닌 곳 (그림·문양·구운 그림자) 은 가짜 요철이 생긴다. 낮은 해상도 (128–256) 라 요철이 굵다. 정확히 하려면 덮어쓰기 PNG.
- 광원이 실제 레벨 조명이 아니다 (카메라 위 고정 방향). 구운 조명과 방향이 맞지 않을 수 있다 — 그래서 세부 배율을 ±40 % 로 묶었다.
- 화면 미분 좌표계는 2×2 쿼드 단위라 아주 작은 삼각형·먼 곳에서 거칠고, 밉맵된 노멀맵은 멀리서 평평해진다.
- 부드러운 법선은 위치 양자화 1/64 단위로 묶는다. 서로 다른 서브메시 (머티리얼) 사이에서는 평균하지 않는다.
- 추가 레이어 (환경맵 반사·가산 레이어), 파티클, 이펙트 GO 의 가산 파트, UI 에는 적용하지 않는다.
- 덮어쓰기 PNG 는 크기·규약 검사를 하지 않는다 (§2 규약을 지켜야 함).
